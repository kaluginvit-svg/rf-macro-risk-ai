# Историческая калибровка системы оценки рисков

## Цель

Убедиться, что новая 4-зонная шкала и формула scoring.py корректно воспроизводят исторические периоды: в периоды острого стресса — красная/чёрная зона, в спокойные периоды — зелёная/жёлтая.

## Контрольные периоды

### 1. Февраль–март 2022 (острый стресс)

Событие: полномасштабное вторжение в Украину, антироссийские санкции, заморозка резервов ЦБ, остановка торгов на Мосбирже (25 февраля — 21 марта), внеплановое повышение ставки с 9,5% до 20%.

Ожидаемый результат: `red` или `black`

Ключевые критерии, которые должны сработать:
- `moex_trading_halt` (triggers_black=true) — trading halt 3+ weeks
- `cb_emergency_rate_hike` (triggers_black=true) — rate 9.5% -> 20% on 28.02.2022
- `ruble_depreciation_shock` — RUB 75 -> 110+
- `cash_fx_premium_spike` — premium 50%+
- `new_fx_controls_severe` — полный запрет продажи валюты нерезидентам
- `deposit_outflow_mass` — массовое снятие вкладов
- `systemic_bank_resolution` — санации под угрозой
- `ofz_market_stress` — торги ОФЗ остановлены

Минимальный ожидаемый score при корректной калибровке: 70+ (red) или black через moex/cb_emergency.

Событие: объявление мобилизации (21 сентября), резкое ослабление рубля, отток населения.

Ожидаемый результат: `yellow` или `orange`

Ключевые критерии, которые должны сработать:
- `ruble_depreciation_shock` (рубль с 60 до 70+ за неделю)
- `cash_fx_premium_spike` (нехватка наличной валюты)
- `deposit_outflow_mass` (вывод средств перед отъездом)
- Возможно `force_majeure_state_event` (объявление частичной мобилизации)

Минимальный ожидаемый score: 20–40 (yellow/orange).

### 3. Июнь 2023 (кратковременный шок)

Событие: мятеж Пригожина / марш Вагнера (23–24 июня 2023).

Ожидаемый результат: `yellow` или `orange` (событие длилось 24 часа, быстро разрешилось)

Ключевые критерии:
- Возможно `force_majeure_state_event` (watch/warming_up)
- `ruble_depreciation_shock` (кратковременное ослабление)

Ожидаемый score: 15–35. Система не должна выдавать red/black по однодневному событию без финансовых последствий.

### 4. Декабрь 2023 (умеренный стресс)

Событие: рубль ослаб до 100+ за доллар, ЦБ повысил ставку до 16% (плановое заседание), введены экспортные требования к продаже валюты.

Ожидаемый результат: `yellow` или `orange`

Ключевые критерии:
- `ruble_depreciation_shock` (watch или warming_up)
- `deposit_rate_spread_spike` (ставки по вкладам выросли)
- `ofz_yield_curve_inversion_spike`
- `inflation_reacceleration` (инфляция ускорялась)

Ожидаемый score: 20–45.

### 5. Спокойные периоды 2024–2025

Событие: относительная финансовая стабильность при высокой ставке (16–21%), продолжение войны без острых финансовых шоков.

Ожидаемый результат: `green` или `yellow`

Система НЕ должна давать постоянный `red`:
- Изолированная новость без подтверждения не должна повышать риск
- Повтор старых тем без новых данных должен давать novelty_multiplier=0.25

Ожидаемый score: 5–30.

## Как запустить калибровочный прогон

1. Установить `CRITERIA_FILE=criteria.json` в `.env`
2. Запустить прогон с флагом `--provider mock` для проверки структуры без API:
   ```
   uv run python src/lc_money_alert_bot.py --provider mock
   ```
3. Для реального прогона с историческими данными (требует изменения дат в запросах):
   - Создать временную копию criteria.json с датой нужного периода в search_query
   - Запустить прогон с `--provider openai` или `--provider anthropic`
4. Проверить `research_ledger.json` — зафиксированы ли события с правильными cooldown_until
